# User Domain

## 핵심 규칙

- 닉네임은 저장 전에 앞뒤 공백을 제거한다. 공백을 제거한 결과는 비어 있지 않아야 하며, 최대 6자 제한은 공백을 제거하기 전 입력값을 기준으로 검사한다.
- 로그인 계정의 `providerId`는 공백일 수 없고 최대 255자다. `(provider, providerId)` 조합은 전체 계정에서 고유하다.
- `LoginProvider`의 enum 값이 곧 사용 가능한 로그인 방식을 뜻하지 않는다. 현재 `ProviderTokenAuthenticator`가 등록된 로그인 방식은 `GUEST`뿐이다.
- 리프레시 토큰은 고유한 64자리 16진수 해시로 저장한다. 폐기되지 않았고 검사 시각이 만료 시각보다 이전일 때만 활성 상태이며, 다시 폐기해도 최초 폐기 시각을 유지한다.
