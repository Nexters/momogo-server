# Group Domain

## 핵심 규칙

- 그룹명은 공백일 수 없고 최대 16자다.
- 초대 코드는 영문 대문자와 숫자로 구성된 6자리이며 그룹 전체에서 고유하다. 삭제된 그룹의 초대 코드도 중복 검사에 포함해 재사용하지 않는다.
- 같은 그룹과 회원 조합의 그룹 멤버는 하나만 유지한다. 탈퇴한 회원이 다시 가입하면 기존 그룹 멤버를 제거하고 새 그룹 멤버를 만든다.
- 하나의 그룹에는 활성 회원이 최대 8명까지 가입할 수 있다.
- 회원이 그룹에서 탈퇴하면 그룹 멤버를 soft delete하고, 마지막 활성 회원이 탈퇴하면 그룹도 soft delete한다. 삭제된 그룹은 활성 그룹 API의 조회·수정·가입 대상에서 제외한다.
